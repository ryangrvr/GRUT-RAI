Software and provenance archive of GRUT-RAI, the computational and audit infrastructure of the GRUT (Grand Responsive Universe Theory) research program. It is released at a consolidation point, together with the program's public record.

The companion paper is GRUT — Grand Responsive Universe Theory: Consolidated Theory, Formal Architecture, Results, Limits, and Completion Program by D. Ryan Grover, DOI 10.5281/zenodo.22983638. All versions of the theory record are under 10.5281/zenodo.19803663. The paper's Markdown source, LaTeX build, and PDF are included under uploads/.

This archive contains everything the paper cites:

  • pre-registration charters, each committed before its run;
  • executable instruments (calc/): the campaign instruments are pure Python standard library, and some foundations instruments need numpy;
  • SHA-256-hashed result artifacts;
  • verdicts and formalizations;
  • the foundations record, archived from the adjudicator-track branch.

Owner rulings are recorded as files in the repository and on GitHub Issue #2.

Scope statement: this is an in-house research record.

  • No external peer review is claimed.
  • No experimental validation is claimed.
  • No confirmed novel quantitative prediction is claimed.
  • It is not a completed theory of everything.

Earlier releases in this lineage carried stronger claims that the current record has demoted. Where they conflict, the current record governs (paper, Section 29).
