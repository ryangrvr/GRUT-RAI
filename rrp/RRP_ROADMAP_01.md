# RRP_ROADMAP_01 — the program's road (owner determination, 2026-09-23)

**Recorded verbatim in substance; governs sequencing. No new gates added — "let the system:
collect → compare → extract → challenge → simplify."**

## The road

Start with reality → map what established physics actually requires → look for structures
shared across otherwise different theories → strip away formulation-specific baggage → see
what remains.

1. **Finish the broad physics map** (corpus expansion across all major domains — tranche 2:
   condensed matter/emergence, nonequilibrium systems, classical field theory,
   mathematical/foundational structures; further tranches as needed). The goal is not proof;
   it is a map of what reality demonstrably does, queryable for "what keeps showing up."
2. **Look for the common structures** — patterns surviving translation into a common
   language. Candidate themes (relationships, constraints, locality, state spaces,
   transformations, symmetries, conservation, composition, causal structure,
   coarse-graining, information loss vs recoverability, observer/system distinctions,
   emergence, irreversibility, scale dependence) are candidates only: **none is assumed
   fundamental; the cross-domain comparison decides.**
3. **Separate the genuinely universal from the language** — the heart of the program. For
   each cross-domain recurrence: different things that look similar, or different
   mathematical expressions of one structural requirement? Adjudicated through the typed
   correspondence classes (identity → equivalence → structural correspondence → analogy →
   vocabulary coincidence); no forced answers.
4. **Find the irreducible remainder.** Three pre-registered informative outcomes:
   **A** — a small common structural core exists; **B** — several incompatible cores by
   regime; **C** — no meaningful common core. All three ship as answers. Only if A: the
   next question becomes "why does reality have this particular structural core?" — and only
   there could an underlying theory eventually enter.

## The reversal that distinguishes RRP from GRUT

GRUT proposed an answer first (responsive substrate + memory + response) and spent its
effort testing whether reality supported that architecture. RRP reverses the direction:
**do not decide what the substrate is; first determine what any substrate, ontology, or
theory would have to accomplish** — and only much later ask what is the simplest thing
capable of doing all of it. The door stays open to structures that look nothing like GRUT
(algebraic, information-theoretic, causal, network, geometric, unfamiliar) — and to the
outcome that there is no unique underlying structure.

## Standing instruction

The current processes run without interruption: corpus tranches → typed comparison →
requirement extraction → adversarial challenge → simplification/minimality → the
requirements picture as a whole. If a pattern appears, **follow the pattern rather than
deciding beforehand what it has to be.**
