# RRP_03_CHARTER — Recursion Invariant

**Date:** 2026-09-24. **Authority:** owner ruling following RRP-02 round 1. **One
question:**

> **Is conservation of suppliedness up to type conversion invariant under a precisely
> defined class of theory extensions and reformulations — or does it merely recur because
> each framework introduces a new specification space by construction?**

## 1. The fork (both branches deliverable, pre-registered)

- **BRANCH 1 — BOOKKEEPING:** the recursion is a property of the architecture of formal
  description itself (any sufficiently rich specification system exhibits it). Then RRP
  has discovered a fact about scientific-theory architecture, not about nature. The branch
  closes honorably: recorded, and the "what fixes S" question is demoted accordingly.
- **BRANCH 2 — INVARIANT:** a precise invariant persists under the defined map class,
  *and* a discriminant separates the physics instances from generic formal systems. Only
  then does "what fixes S" become substantially more serious.

**The null hypothesis of this phase is Branch 1.** The meta-problem is not a caveat here;
it is the thing being tested.

## 2. Discipline

No second six-program audit round (owner ruling — two levels of the phenomenon suffice as
data). "Debt" remains metaphor until formalized — the phase's first task is to attempt the
formalization and report honestly if it fails (a vacuous partial order is a finding, not
an embarrassment). The class-4 gate stays exactly where it is, with its named converters.
No ontology; no substrate; C5 binds (nothing universal over undeclared classes); every
candidate invariant and discriminant carries its kill condition at birth. Null models are
mandatory: a candidate invariant that has not been tested against non-physics
specification systems has not been tested.

## 3. Instruments (small, bounded)

(1) A formalization attack: can the typed comparison of supplied content be made a
non-vacuous partial order on the program's ~14 concrete audited ledgers, with II′ stated
as absence of strictly-reducing maps? (2) A logic/model-theory null model: does the
recursion hold in pure formalism, and do *genuine* eliminations exist there? (3) An
engineered-systems null model (specification stacks with no physics in them). (4) A
discriminant hunt: if the coarse recursion is universal, what — precisely — do the physics
instances have that the nulls lack? Synthesis by the main session; the phase closes with a
branch verdict at recorded strength.
