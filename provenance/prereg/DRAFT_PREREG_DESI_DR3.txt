PRE-REGISTRATION -- THE DESI DR3 FALSIFICATION THRESHOLD FOR THE NO-CROSSING EXPORT
BLIND-SAFE: yes. This file contains no result numbers from the data it judges.

WHY NOW. DESI completed its five-year survey (announced April 2026). DR3 / first full-survey
BAO cosmology is expected in 2027. A threshold set before the data is worth something; set
afterward it is worth nothing, and this is the last window in which it can be set honestly.

THE NODE THIS JUDGES. rung7_w3_nocrossing_export (tier to-derive), with rung7_wz and
rung7_w2_wa_sign. The framework's sourced statement is w = -1 flat; its no-crossing result --
held at to-derive, generic where it holds (Vikman 2005), and conditional on the open
single-pole conjecture -- forbids a single passive channel from crossing w = -1.

CURRENT STATE, RECORDED SO THE THRESHOLD IS NOT SET AGAINST A MISREMEMBERED BASELINE. As of
this writing the DESI DR2 preference against a cosmological constant is parametrization-
dependent and, on the reading this program adopts, not consolidated as physical: the apparent
crossing is argued to be an artifact of the CPL (w0-wa) parametrization, which enforces
crossing by construction (Dinda & Maartens arXiv:2504.15190; Keeley, Shafieloo & Matthewson
arXiv:2506.15091), and the highest published figure softened on the DES re-analysis
(arXiv:2508.10514). No combination has reached the threshold below by a model-independent
route. THE FRAMEWORK IS NOT FALSIFIED BY PRESENT DATA, and this file does not pretend it is.

*** THE THRESHOLD, FROZEN ***
The no-crossing export is FALSIFIED by, and only by:
  a detection of w(z) < -1 at any redshift, at >= 5 sigma, that is
  (i)  MODEL-INDEPENDENT: obtained by a reconstruction that does not impose a crossing-capable
       two-parameter form -- explicitly NOT CPL/w0-wa, and not any parametrization whose
       functional form permits crossing by construction;
  (ii) ROBUST ACROSS THE RELEASE'S OWN HEADLINE COMBINATIONS, not confined to one supernova
       compilation or one full-shape variant; and
  (iii) PUBLISHED by the collaboration or in the peer-reviewed literature, with the
       reconstruction method stated.

WHAT EXPLICITLY DOES NOT COUNT, named in advance so it cannot be argued afterward:
  - a CPL-parametrized preference at any significance, however large;
  - a result driven by a single supernova compilation, or one that disappears when that
    compilation is swapped;
  - a full-shape-specific or combination-specific excursion not reproduced across the
    release's headline combinations;
  - a strengthening of the evidence against a cosmological constant that is not itself a
    crossing detection. Lambda can fail without w crossing -1, and that outcome falsifies
    nothing here.

THE THREE OUTCOMES, ALL FIRST-CLASS:
  (a) THRESHOLD MET -> the no-crossing export is REFUTED as stated. Consequences execute at
      the named nodes, per the sealed termination condition's R2; this file executes nothing.
  (b) THRESHOLD NOT MET AND THE PREFERENCE IS CROSSING-SHAPED BUT PARAMETRIZATION-DEPENDENT
      -> STILL OPEN, cause stated in plain words. Not a survival claim: the framework is not
      thereby confirmed, and the register books no credit for it.
  (c) NO RELEASE, OR THE RELEASE DOES NOT ADDRESS CROSSING MODEL-INDEPENDENTLY -> STILL OPEN,
      cause stated. Silence is not evidence in either direction.

WHAT THIS FILE DOES NOT DO. It does not amend the sealed termination condition, does not
create a new channel, and does not fire any register trigger. It fixes ONE predicate in
advance so that a later reading of DR3 cannot be fitted to the framework's convenience --
which is the only thing a pre-registration is for.

THE HONEST CEILING, STATED ON THE FACE. "Passive single-mode dissipative vacuum" is this
program's own construct, not a named model in the literature. The falsification logic is
sound -- such a model cannot cross w = -1 -- but the mapping from that construct onto the
observables DR3 will report is not established in any published work located to date. A
reader should treat this threshold as this program's commitment about its own model, not as
a test the cosmology literature would recognize as addressed to it.
