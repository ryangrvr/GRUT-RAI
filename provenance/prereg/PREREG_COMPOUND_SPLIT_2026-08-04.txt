THE ATOMICITY TEST (the same dissociation logic used everywhere else in this program):
    An input is COMPOUND if one part can be discharged INDEPENDENTLY of the rest.
    It is ATOMIC if no part discharges alone.
Worked instance already established: semiclassical_sourcing fails it -- S1 ("there is a state and an
expectation functional on the observable algebra") is dischargeable without S2 ("the metric couples
to the MEAN of that functional"), which is exactly why only S1 recurs in quantum foundations.

DIRECTIONAL GUARD: DEFAULT-BROKEN TOWARD COMPOUND. Assume each node splits until shown otherwise,
and record the ATOMICITY ARGUMENT FOR EVERY NODE -- not only for the ones that split. A node
declared atomic without a recorded argument is an unexamined node wearing a verdict.
OPPOSITE GUARD, equally binding: DO NOT OVER-SPLIT. Arbitrarily fine slicing inflates a count
meaninglessly and would be the mirror failure. If a proposed part cannot be discharged ALONE, it is
not a part. Two guards pointing opposite ways is the correct shape here.
