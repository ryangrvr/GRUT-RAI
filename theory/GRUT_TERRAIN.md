## The four-axis taxonomy

A mature framework must distinguish what it **selects** from what it merely **permits**.
The whole low-ℓ-CMB and Koide investigations reduced to exactly this distinction.

| Axis | Meaning | The test |
|---|---|---|
| **SELECTED** | the theory *predicts* it; falsifiable | could the theory have given a different value? If essentially no → selected |
| **PERMITTED** | the theory is *compatible* with it but does not force it | does a free coefficient / external value have to be supplied? If yes → permitted |
| **HOSTED** | taken as input from the SM / observation | GRUT carries it, does not generate it |
| **ANCHORED** | numerically fixed by an *observed* quantity, not first principles | remove the observation — does the number survive? If no → anchored |

The governing rule for all future work:

> **A result counts as progress only if it moves a quantity *up* the ladder —
> hosted/anchored → permitted → selected. A beautiful construction that selects
> nothing new is recorded as speculative and not banked.**
