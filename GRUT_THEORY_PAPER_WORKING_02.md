## 1. THE RESULT OF THIS PHASE, STATED ONCE

> **The present GRUT result is not that the supplied remainder is small
> in an absolute sense; it is that repeated counterexample-driven
> attacks have reduced a previously diffuse assumption set to a small
> number of explicitly identified structural inputs and unresolved
> seams.**

That sentence is the paper's headline, and the four-part structure
below is its anatomy. GRUT is a **dependency-resolved theory**: every
statement in it is typed (derived-in-class **D** / constrained **C** /
supplied **S** / unresolved **U**), every supplied item is reduced to
its smallest attacked form, every red gate is preserved where it
lives, and completion is a finite list of typed problems in which
**a principled irreducibility verdict is a legitimate endpoint** — the
project carries no implicit rule that every input must eventually be
derived.

The formal chain, with its one binding caveat:

    𝒪_local → 𝒞_continuum → ℐ → [𝔄] → 𝒢 → ℱ_eff → 𝒢_grav

**𝔄 is bracketed because it is a cross-cutting condition on the whole
chain, not a link in it** (Part II). The chain's honest split, which
Draft 01 exposed and this draft makes structural:

- **the generative core** (Part I): 𝒪_local → 𝒞_continuum → ℐ →
  recoverable structure — demonstrated, within stated classes, to
  *generate* memory, continuous spectra, irreversible response,
  constrained influence data, higher-cumulant structure, and (given
  access) spatial geometry;
- **the conditional branch** (Part III): (ℐ, 𝔄, 𝒢) → ℱ_eff → 𝒢_grav —
  where the remaining supplied structure begins to dominate and every
  derived statement is conditional on named inventory items.

Object definitions are carried from Draft 01 §2 unchanged and are not
repeated; this draft reorganizes the arrows, it does not redefine the
objects.

## PART II — THE STRUCTURAL INTERFACE (𝔄, cross-cutting)

**𝔄 is a condition on the whole chain, not a stage of it.** It is
consumed at least three times, in different roles:

1. **Upstream (partition role):** the retained sector of Arrow I.1 is
   an 𝔖-choice — the kernel is downstream of it and could never be
   primitive (P-1).
2. **Midstream (reach role):** every reconstruction and every
   decidability question class-splits by access reach — geometry
   (GS-1's selection table), unit-change decidability (SX-1 L-C),
   microscopic underdetermination (D-1), the single-site collapses.
3. **At the boundary (event role):** access-boundary *changes* are
   exactly where hidden differences become physical (P-5's quench
   split) — the interface has physical content precisely at its
   events.

The interface's own record:

| content | status |
|---|---|
| the access-relativity principle: a distinction is physical exactly as far as it changes accessible influence data | **D** (D-1, P-5; the campaign's most-repeated finding) |
| the closure, given a seed | canonical (**D**) |
| the seed itself | **S** — attacked and not derived: closure non-injective, minimality path-dependent, degenerate control unselectable (one **red**); the deepest item of stem A |
| factorization / embedding / medium-vs-relational vocabulary | representational (**D** demotions) |
| why access exists at all (the observer question) | **U** (unposed) |

The four-part structure of this paper depends on Part II being its own
block: pushing 𝔄 into the chain as one arrow would either hide the
upstream consumption (making Arrow I.1 look unconditional) or hide the
event physicality (making access look like pure bookkeeping). Both
misreadings are refuted by the record.

### IV.2 The problems, typed

C1–C7 are **not seven interchangeable next experiments**. They fall
into four qualitatively different classes:

| class | problems | what closing them does |
|---|---|---|
| **architectural closure** (can the architecture close its own seams and stems?) | **C1** stationarity seam · **C2** causal structure · **C3** access seed · **C4** probe structure | changes what the *theory itself* is: each converts a seam/stem into either derived structure or a proved axiom |
| **quantum foundation** | **C5** ℏ / Born / outcomes | independent of the gravity branch entirely; prices the whole framework |
| **integrity block** | **C6** the red gates | consistency housekeeping of what already exists; never new physics, never by prose |

Each problem carries its dual closure (success criterion **and**
principled-irreducibility criterion) exactly as stated in Draft 01 §6;
those statements are carried unchanged and not repeated.

### IV.3 What C7 actually tests (architectural analysis, no computation)

The owner's question: is the retained-sector/QFT confrontation testing
the theory's core, or only a downstream conditional branch? The
dependency graph answers it directly:

**C7 tests the conditional branch, not the generative core.**

- **What C7's premises consume:** the T3 mapping runs through the
  identification chain — CARRIER (I2), the probe structure (I3–I6),
  the retained-sector class selection (conditional on I2+I3, with L1
  open inside it), and the sector's microscopic content (I11). Every
  one is Part-III structure.
- **What a mismatch would kill:** the gravitational identification —
  the ℱ_eff → 𝒢_grav branch — at a certified wall. The generative core
  survives such a death **as generic open-system results, explicitly
  stripped of the gravitational reading** (this consequence is already
  pre-registered in the skeleton's §11 and is inherited here, not
  invented).
- **What a pass would establish:** discriminator-grade support for the
  identification — with the pre-registered caveat that one exponent
  class from a small discrete set is weak Bayesian evidence — while
  discharging **no** stem, **no** seam, and none of C1–C5. The
  inventory after a C7 pass is the same inventory.
- **The L1 exposure:** the confrontation's sector-selection premise
  currently sits in the exception class of the chain's own
  universality argument. A C7 run before L1 is addressed tests a
  branch whose selection is not yet self-consistent — the result,
  either way, would be conditional on exactly the structure most in
  question.

**Consequence (analysis, not a ruling):** C7 is the most dramatic test
and the least architecturally informative one available right now. It
cannot close a seam, cannot discharge a stem, and its own premises
route through L1. The architecturally decisive problems are C1–C4
(they change what the theory is); C5 prices the framework
independently; C6 is owed housekeeping wherever instruments are next
built. This analysis deliberately stops short of selecting — the
decision between C1/C2/C5/C6/C7 (the owner's stated menu) is the
owner's, now with the dependency answer on the table.
