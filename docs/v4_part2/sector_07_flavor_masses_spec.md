# Sector 7 — Flavor / Masses: Specification

## Sector name
Flavor / Masses

## Status
**Open, with exploratory entry point**

## Claim boundary

**What is claimed:**
- The electroweak host (Sector 2) provides the mass-generation mechanism: M_f = y_f v / sqrt(2)
- Yukawa couplings y_f are FREE parameters (same status as in the SM)
- Mass-matrix and CKM diagnostic utilities are provided
- The fermion mass hierarchy is documented but not explained

**What is NOT claimed:**
- No derived mass hierarchy
- No derived CKM matrix
- No generation-count explanation (why 3 families)
- No Yukawa reduction
- No beyond-SM flavor prediction

## Dependencies
- **Sector 2:** Electroweak host (Higgs mechanism, Yukawa coupling)

## Closure condition
Closure would require deriving at least one of: mass ratios between generations, CKM mixing angles, or the number of generations — from the GRUT constitutive structure rather than as free inputs.
