## 3. The Alpha-Through-Gamma Arc

### 3.1 Why Each Stage Was Necessary

**Alpha (Division):** Book VII Gamma §8 projected D4-conditional as a side consequence of M4 verification, but this was aggregate reasoning without route-by-route analysis. Alpha provided the dedicated division audit: testing six route families, identifying two genuinely new M4-dependent capabilities (full-boundary conditioning, post-fission carrier-driven recovery), and verifying the nonviable-daughter rate drops from ~3–8% to ~1–3%.

**Beta (Lineage):** D4-conditional describes single-generation division quality. Whether lower per-generation failure translates into multi-generation lineage robustness requires separate analysis — the compounding behavior, recovery-loop dynamics, and HIC-bottleneck identification are lineage-level questions that cannot be answered by a division audit. Beta provided this, showing per-gen loss drops to ~0.5–1.5% and single-lineage half-life reaches ~50–140 gen.

**Gamma (Adaptive):** L4-conditional describes lineage persistence. Whether longer persistence enables richer adaptive dynamics requires separate landscape analysis — the carrier-related trait axes, multi-domain coupling, and three-phase enrichment structure are adaptive-level questions that cannot be answered by a lineage audit. Gamma provided this, showing the landscape broadens from 3–4 to 6–7 axes with ~30–40 gen active enrichment.

### 3.2 How Alpha Enabled Beta Enabled Gamma

**Alpha → Beta:** Alpha verified D4-conditional (nonviable rate ~1–3%). Beta used this as its input: lower nonviable rate → exponentially higher pre-division copy numbers → lower per-gen essential-type loss. Without Alpha's D4 verification, Beta would have been working from the unverified Book VII projection.

**Beta → Gamma:** Beta verified L4-conditional (half-life ~50–140 gen). Gamma used this as its input: longer lineage persistence → more generations for selection to act → ability to explore carrier-related trait axes that take ~25–40 gen to optimize. Without Beta's L4 verification, Gamma would lack the persistence window needed for Phases 2 and 3 of enrichment.

### 3.3 Dependence on Book VII Carrier Bridge

Every Book VIII gain traces back to the carrier bridge (Book VII Beta, provisionally committed in Book VII Gamma):

- **D4-conditional:** Full-boundary conditioning and post-fission recovery both require carrier-delivered energy at remote sites.
- **L4-conditional:** Copy-number deepening requires carrier-driven P1 system-wide. Post-fission recovery requires carrier flux in daughters.
- **A4-conditional:** Carrier-related trait axes exist only because the carrier exists. Gradient amplification requires ~30% directed fraction. Multi-domain coupling requires carrier-backed energetic × division × lineage interactions.

If ΔG < 28 kT, the carrier fails, and the scaffold reverts to M3/D3/L3/A3 — the Book VI terminal state plus the M3 expansion from Book VII Alpha.

### 8.2 Handoff Decision

**Recommended Book IX first target: A — Unconditional M4 verification / carrier-barrier stabilization.**

Justification:

1. **Highest structural leverage.** Every conditional gain in Book VIII (D4, L4, A4) depends on M4, which depends on ΔG ≥ 28 kT. If unconditional M4 can be demonstrated, all conditional gains become unconditional simultaneously. No other single target has this multiplier effect.

2. **Most mature prerequisite.** Program W0 already identified a specific physical mechanism (selection-rule-protected quantum metastability of the K=2 (N=2, ℓ=0) excited state) and a derivable inequality (α_g²(M_sk/kT) ≥ 149). The two remaining open items are: (a) computing the two-gauge-boson decay rate, and (b) assessing dissipation-background effects. These are tractable within the existing formalism.

3. **Natural continuation.** Book VII established M4-conditional → Book VIII extracted D4/L4/A4-conditional → Book IX should attempt to resolve the conditionality. This is the same progressive-deepening pattern the program has followed throughout.

4. **Alternative candidates are less mature.** Active transport (B) likely requires a new bridge postulate. Ecology (D) and innovation (E) have no visible structural path. Currency-cycle refinement (C) is incremental. Inheritance closure (F) is downstream of unconditional M4.
