## Rationale

The original labeling ("GRUT-II," "GRUT-III," "GRUT-IV") implied these were successor theories with independent identity. In retrospect, they were all sector audits testing specific extensions of the same GRUT-I constitutive architecture. They shared the same equation, the same bridges, and the same cost ledger. They were not new theories — they were terminal investigations of the first theory.

The name "GRUT-II" is now reserved for a genuinely new program with a different organizing principle.

## What "GRUT-II" Now Means

GRUT-II is reserved for: **A Theory of Scaling in a Responsive Reality** — a new program that builds on the GRUT-I grammar (G1-G6) but addresses a fundamentally different question: how do the constitutive dynamics SCALE across regimes, from quantum to cosmological, and what new structures emerge from the scaling rather than from the contraction?

This is not a stochastic extension, not a noise model, not a self-consistency trick. It is a new theory.
