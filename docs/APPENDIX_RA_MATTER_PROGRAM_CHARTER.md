## 1. Program Objective

Appendix R investigates whether GRUT can support matter-like structure --
bosonic objecthood, localization, stabilization, composite matter, and a
disciplined path toward chemistry -- building on quantum foundations (Q)
and classical bosonic object route (M/N/O).
