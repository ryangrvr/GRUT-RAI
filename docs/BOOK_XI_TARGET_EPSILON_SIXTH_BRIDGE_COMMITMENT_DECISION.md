Option C (hybrid) is the only position that is simultaneously honest about the current state (one surplus demonstrated; two open) AND structurally productive (declares the frontier program, defines its gates, and enables quantification work without premature identity claims).

Option A (commit now) is premature — it would declare a sixth bridge on one surplus. Option B (defer entirely) would abandon the frontier program unnecessarily, since the GGB has real demonstrated content.

**If the GGB is committed, what exactly is GRUT doing gravitationally that GR alone is not?**

1. **Resolving singularities** (demonstrated) — GR cannot do this; GRUT's negative ρ_eq can.
2. **Providing a native cosmological-constant analog** (conditional) — GR requires ad hoc Λ; GRUT's constitutive w = −1 could replace it. But: NOT YET COMPUTED.
3. **Introducing frequency-dependent GW modification** (open) — GR GW is undamped; GRUT's τ-dissipation modifies scalar admixture. But: NOT YET QUANTIFIED.

**Is the GGB modifying gravity or mostly supplying exotic matter?**

Honest answer: **mostly supplying exotic matter.** The Einstein field equations are installed as a bridge. The metric dynamics are Einstein's. GRUT's contribution is the source T^Φ — which has exotic properties (ρ < 0, w = −1). These exotic properties MODIFY the solutions to Einstein's equations in specific regimes. This is matter-modifying-solutions, not gravity-replacing-equations.

**This is not duplication** — T^Φ is genuinely GRUT-native and genuinely exotic. But it is **not yet completion** — the modifications are regime-specific (compact interior) with two other regimes unquantified. Full completion would require all three surpluses to be demonstrated.

**Verdict:** The GGB is at the boundary between "enhanced matter-within-GR" and "genuine gravitational completion." It crosses that boundary if Surpluses 2 and 3 survive. It does not cross it with Surplus 1 alone.
