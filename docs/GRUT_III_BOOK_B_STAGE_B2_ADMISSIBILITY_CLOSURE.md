## 1. M_t Closure Test

### The question

M_t = (Φ_t − X_t)² was included in B1 as a "memory/residue state." Is it an independent state variable with its own dynamics, or is it purely derived from (Φ_t, X_t)?

### Analysis

**Test for recursion:** Can M_{t+Δt} be computed from M_t alone (without knowing Φ_t and X_t separately)?

Deterministic case:
```
M_{t+Δt} = (Φ_{t+Δt} − X_{t+Δt})²
         = ((1 − Δt/τ)(Φ_t − X_t) + (X_t − X_{t+Δt}))²
         = ((1 − Δt/τ)√M_t ± ΔX)²
```

The sign of (Φ_t − X_t) is lost in M_t = (Φ − X)². Given only M_t, one cannot determine whether Φ > X or Φ < X. Therefore M_{t+Δt} cannot be computed from M_t alone when X changes (ΔX ≠ 0).

For constant X: M_{t+Δt} = (1 − Δt/τ)² M_t. This IS a self-contained recursion. But it is trivially derived from the Φ update — it carries no independent information.

Stochastic case: M_{t+Δt} depends on the noise realization, which is independent of M_t. No self-contained recursion exists.

### Decision

**M_t is path-functional bookkeeping only (option ii).** It is not an independent recursive state variable. It is a derived diagnostic computed from (Φ, X) at each timestep.

**Action:** Remove M_t from the minimal Markov state. The minimal state is:

```
S_t^{min} = (Φ_t, X_t, F_t)
```

M_t is retained as a DIAGNOSTIC OBSERVABLE (computed from S_t, not evolved independently), renamed:

```
V_t ≡ (Φ_t − X_t)²    [Lyapunov diagnostic, not a state variable]
```

**Justification:** In the Markovian regime, the future evolution of Φ depends on (Φ_t, X_t, τ, D) — not on V_t or on any history functional. V_t can always be reconstructed from (Φ_t, X_t). Including it as a state variable would be redundant and would falsely suggest that the system "remembers" its deviation independently of its current position.

**Gate B2-G1 resolution: RECURSIVE STATE → BOOKKEEPING.** M_t removed from minimal state. V_t retained as diagnostic.

## 2. Admissibility Feedback Architecture

### Model D: Diagnostic (post-hoc labeling)

**Mathematical form:**

```
Evolution:  Φ_{t+Δt} = U_{Δt}(Φ_t, X_t, ξ_t)         [unconditional]
Labeling:   A[{S_s}_{s=0}^t] → {ADMISSIBLE, INADMISSIBLE, BOUNDARY}   [after the fact]
```

U generates the path. A classifies it afterward. A has NO effect on the realized evolution. Every path generated by U is a path; A merely sorts them.

**Physical interpretation:** GRUT is an open-system EFT. The constitutive law generates ALL trajectories (deterministic + stochastic). Admissibility is a filter applied by the theorist to identify which trajectories are physically meaningful (within regime, satisfying FDT, etc.). The universe does not "know about" A — A is an analytical tool.

**Regime validity:** All regimes where U is defined. A is a classification of paths, not a dynamical rule. It works wherever paths exist.

**Failure modes:**
- Model D cannot distinguish two paths that differ only in their HISTORY but have the same current state. In Markovian dynamics, this is not a failure — the future depends only on the present. But in any non-Markovian extension, history matters, and a diagnostic-only A cannot enforce history-dependent constraints dynamically.
- Model D cannot prevent the system from entering an INADMISSIBLE state. It can only report that it has done so.

### Model C: Constraining (trajectory pruning)

**Mathematical form:**

```
Proposal:    Φ* = U_{Δt}(Φ_t, X_t, ξ_t)         [candidate step]
Filter:      if A_local(Φ*, X_{t+Δt}, F*) = ADMISSIBLE:
               Φ_{t+Δt} = Φ*                      [accept]
             else:
               Φ_{t+Δt} = project(Φ*, admissible set)   [project/reject/resample]
```

U proposes. A filters. The realized evolution is the INTERSECTION of U and A. Paths that would leave the admissible domain are projected back or rejected.

**Physical interpretation:** GRUT is a constrained dynamics. The constitutive law operates only within the admissible domain. The boundary of admissibility acts as a physical constraint — like a wall in configuration space. The theory predicts only the trajectories that are BOTH generated by U and accepted by A.

**Regime validity:** The constraining version requires:
- A well-defined projection operator onto the admissible set (what does "project back" mean operationally?)
- The admissible set must be convex or at least connected (for projection to be unique)
- The projection must preserve the CTP structure (does projecting Φ back into the admissible set violate the CTP unitarity conditions?)

These are nontrivial requirements. In the current Markovian/linear regime, the admissible set IS all of configuration space (any Φ is admissible if the constitutive equation is satisfied and the regime flags are 1). The constraints are on the DYNAMICS (the update rule), not on the state space. There is no nontrivial projection.

**Failure modes:**
- In the Markovian/linear regime, Model C reduces to Model D because the admissible set is the set of all paths generated by U with regime flags 1. The filter A never rejects a U-generated path that stays within the flagged regime.
- Model C becomes nontrivial ONLY if there exist paths where U proposes a step that A rejects. This requires either: (a) nonlinear dynamics with multiple attractors (where U might push toward one attractor but A requires another), or (b) regime boundaries that U can cross (where U proposes a state outside the controlled domain).

---

### Critical test: Does A ever reject a U-generated step in the current regime?

In the Markovian, linear, deterministic regime:

- U generates: Φ_{t+Δt} = Φ_t + (Δt/τ)(X_t − Φ_t)
- A1 (constitutive equation): U satisfies this BY CONSTRUCTION. A1 never rejects.
- A2 (Lyapunov): dV/dt = −(2/τ)V ≤ 0. Always satisfied BY CONSTRUCTION. A2 never rejects.
- A4 (regime flags): U does not contain any mechanism to drive f₁, f₂, f₃, f₄ to zero if they start at 1 and X varies slowly. The only way a flag drops to 0 is if the EXTERNAL geometry changes (X becomes large, or the driving frequency increases). This is not a U failure — it is an environment change.

**In the stochastic regime:** Noise can kick Φ away from X, potentially violating f₃ (linearity flag) if the kick is large enough. But in thermal equilibrium, the probability of a kick exceeding the linearity threshold is exp(−threshold²/2D), which is exponentially small for threshold >> √D.

**Conclusion:** In the declared Markovian/linear regime, Model C reduces to Model D. The admissibility functional NEVER rejects a U-generated path that starts in the admissible domain, because U is constructed FROM the CTP action which already incorporates all admissibility constraints.

**This is a theorem, not a contingency:** the CTP action, by construction, generates paths that satisfy the CTP unitarity conditions (A5), causality (A6), and the constitutive equation (A1). The regime flags (A4) are EXTERNALLY imposed (they depend on the geometry and driving frequency, not on U). The only way a path becomes inadmissible is if the external conditions change to push it outside the controlled domain.

## 3. Nontrivial Pruning Demonstration

### Attempt: find two trajectories with same (Φ₀, X₀) where both satisfy U locally but only one is globally admissible

**In the Markovian/linear regime:** This is IMPOSSIBLE, and here is the proof.

**Proof of non-pruning in Markov/linear:**

Given (Φ₀, X₀) and the update rule U, the deterministic trajectory is UNIQUE (linear ODE with unique solution). Two different trajectories from the same initial condition would require different noise realizations (stochastic case). But A conditions A1-A7 do not depend on WHICH noise realization occurred — they depend on whether the constitutive equation is satisfied (A1: yes, by construction), whether Lyapunov decreases (A2: replaced by A3 for stochastic), whether FDT holds (A3: statistical, satisfied in equilibrium), and whether regime flags are 1 (A4: determined by external geometry).

**No condition in A distinguishes between different noise realizations that stay within the admissible regime.** Therefore no trajectory that U generates and that maintains F_t = (1,1,1,1) can be pruned by A. All such trajectories are equally admissible.

**QED: Nontrivial pruning is impossible in the Markovian/linear regime.**

### Where pruning COULD become nontrivial

**Scenario 1: Nonlinear dynamics (bistability).** If U has two attractors (Φ* = X_1 and Φ* = X_2 from cubic saturation), and A includes a condition like "the system must converge to the thermodynamically preferred attractor," then A could prune trajectories that converge to the wrong attractor. This requires:
- The nonlinear CTP action (UD2-dependent, not constructed)
- A criterion for "preferred attractor" (entropy, free energy, or geometric argument)

**Status: OPEN.** Not available in the current regime.

**Scenario 2: Non-Markovian dynamics (memory).** If U includes a retarded kernel, two paths with the same current state but different histories would produce different future evolutions. A might then prune paths whose history violates a global consistency condition (e.g., residue R₁ exceeds a threshold). This requires:
- The non-Markovian extension (UD4-dependent)
- A history-dependent admissibility condition beyond A1-A7

**Status: OPEN.** Not available in the current regime.

### Classification

**Nontrivial pruning: IMPOSSIBLE in current regime. POSSIBLE in nonlinear/non-Markovian extensions. Both extensions are OPEN (UD-dependent).**

## 4. Monotonic/Global Functional Check

### Candidate: V_t = (Φ_t − X_t)²

| Property | Status | Condition |
|----------|:------:|-----------|
| Monotone decreasing (deterministic, constant X) | **YES** (dV/dt = −2V/τ) | DERIVED |
| Monotone decreasing (deterministic, varying X) | **NO** (ΔX can increase V) | The source X_t may jump, increasing the deviation. V is not globally monotone under external forcing. |
| Monotone decreasing (stochastic) | **NO** (noise increases V) | Noise kicks V upward. Only the AVERAGE ⟨V⟩ is bounded (by D in equilibrium). |
| Compatible with U | **YES** | V is computed from U-generated trajectories. |
| Compatible with R | **YES** | V = R₀ (the instantaneous residue). |
| Meaningful for admissibility? | **PARTIALLY** | V decreasing confirms convergence (A2). V bounded confirms FDT (A3). But V is not a SELECTOR — it does not narrow the admissible set. |

### Is there anything stronger?

**Entropy-like functional:** In the stochastic regime, the CTP effective action itself serves as a generalized entropy functional. The imaginary part Im S_eff = D ∫ Φ_a² dt ≥ 0 is a non-negative, monotone (in the sense of the second law: entropy production is non-negative). But Im S_eff is a property of the CTP ACTION, not of a single trajectory — it applies to the ensemble, not to individual paths.

**Conclusion:** There is no TRAJECTORY-LEVEL global monotonic functional that both (a) is monotone under all admissible conditions (including noise and varying X) and (b) narrows the admissible set. V_t is monotone only in the deterministic/constant-X case. The CTP entropy production is monotone but applies to ensembles, not trajectories.

**Status: No trajectory-level global monotonic functional exists that is strictly monotone under all admissible conditions.** The Lyapunov function V_t is the best available — monotone in the ideal case, bounded in the stochastic case, but not globally monotone under external driving.
