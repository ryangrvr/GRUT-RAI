## 7. Path-Prioritization Decision

### Option A — Track 1 First: Combined Self-Consistent TOV

**What it could recover:** If the D1–D10 combined result (f > 0) survives on a self-consistent (not fixed-Schwarzschild) background, the interior-metric-positivity surplus is restored from "conditional on proxy/fixed BG" to "demonstrated in self-consistent framework." This would be a genuine recovery of surplus content.

**What it depends on:** Successfully integrating the five-sector coupled system (S_grav + S_macro + S_defect + S_trigger + S_portal) as a self-consistent TOV boundary-value problem. This is computationally demanding but tractable in principle — the D9 Picard strategy provides a starting framework.

**Main risk:** The combined self-consistent result might NOT confirm f > 0. The proxy/fixed-background approximation might have been favorable, and the full self-consistent problem might reintroduce the adverse scalar contribution more strongly than the defect can overcome.

**How it addresses the correction:** DIRECTLY — it tests the exact claim that Gamma/Delta left conditional.

### Option B — Track 2 First: Transient Collapse Phenomenology

**What it could recover:** If A > A_crit is shown to be physically realized during gravitational collapse (not just a mathematical threshold), the transient processing becomes a genuine collapse-era phenomenon with potentially observable consequences.

**What it depends on:** Dynamical analysis of gravitational collapse with the GRUT Φ sector. The collapse.py code exists but uses simplified dynamics. A more complete treatment would need time-dependent GR + T^Φ, which is substantially harder than static TOV.

**Main risk:** The dynamics formalism is less developed than the equilibrium framework. The observational signatures of a TRANSIENT effect are inherently harder to characterize and detect.

**How it addresses the correction:** INDIRECTLY — it pursues a different regime (dynamic collapse) where the adverse static result is less relevant.

### Option C — Maintain Both Equally

**What it does:** Keeps both tracks open without prioritization.

**Main risk:** Doubles scope without doubling formalism. Neither track advances faster.

### Decision: **Option A (Track 1 first)**

**Justification:**
1. **Most direct test of the surviving conditional surplus.** Track 1 directly tests whether D1–D10 f > 0 holds off the fixed background — the exact question Gamma/Delta left open.
2. **Most mature formalism.** The five-sector action is specified (D8 §5.1). The Picard iteration strategy exists (D9). The scalar-only TOV is already integrated (tov_interior.py). Adding the defect sector to the integration is the defined gap.
3. **Highest leverage.** If Track 1 succeeds: surplus restored. If Track 1 fails: the equilibrium path is definitively closed, and the program knows to focus entirely on Track 2 or archive the compact-object frontier.
4. **Track 2 remains available.** Track 2 is not abandoned; it is deprioritized. If Track 1 fails, Track 2 becomes the sole remaining path.
