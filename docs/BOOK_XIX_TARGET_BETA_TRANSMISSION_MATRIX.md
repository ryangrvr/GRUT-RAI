## Table 1 — Relation-Type Definitions

| Type | Strength | What It Means | What It Does NOT Mean |
|------|----------|-------------- |----------------------|
| **Literal reduction** | 1 (strongest) | The core equation governs the sector directly | Not that no additional input is needed |

| **Constraint inheritance** | 3 | The core imposes binding restrictions on the sector | Not that the core generates the sector's dynamics |
| **Construction dependence** | 4 | The sector was built using infrastructure the core creates | Not that the sector would break if the core equation changed |
