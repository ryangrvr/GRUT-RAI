## 3. The Alpha-Through-Gamma Arc

### 3.1 Why Each Stage Was Necessary

**Alpha (gap audit):** Before designing a bridge, the program must confirm that no zero-cost route exists. Alpha tested five families (carrier-biased pore transit, boundary-gated conformation, repair-coupled retention, directed incorporation, pseudo-transport) and all failed. The root cause was localized: internal energetics terminate at internal target sites; the boundary mesh has no functional transport elements. This is the third time the program has followed this pattern (Book V coupling gap → HIC; Book VII M4 ceiling → carrier; Book X boundary gap → CCBG).

**Beta (bridge design):** With the gap confirmed, Beta designed the minimum bridge. Four candidate families were evaluated: CCBG gate (1P + 1p), shuttle/importer (2P + 2p), work cycle (subsumed), pseudo-pump (disqualified). Family F (CCBG) survived as the minimum viable option — a boundary-embedded scaffold with carrier-responsive conformational pore switch. Beta defined the formal cycle but did NOT verify transport thresholds or commit the bridge.

**Gamma (verification + commitment):** Gamma stress-tested the CCBG under honest parameter constraints. T2 was robustly verified: carrier-coupled pore switching provides controlled exchange timing and — critically — waste export of large species impossible at T1. T3 was conditionally verified for large species near the pore-size threshold, where gate-directed import exceeds passive inward flux. For small species, T3 fails (passive flux overwhelms). The CCBG was provisionally committed.

### 8.2 Handoff Decision

**Recommended next sector: A — Gravitational/cosmological sector.**

**Designation: Program W1 — Gravitational Sector Audit (parallel reduction program)** or **Book XI — Gravitational Bridge** depending on scope.

Justification:

1. **Highest structural leverage.** The gravitational sector is where GRUT's native equation (τ dΦ/dt + Φ = X) faces the most precise observational constraints in physics. The Hulse-Taylor binary pulsar measurement constrains gravitational radiation to ~0.2% of the GR prediction. This is a hard falsification gate that no amount of biology-side work can avoid.

2. **Decisive for theory status.** The biology-side scaffold demonstrates organizational capability (reproduction, metabolism, adaptation, transport) at bridge level. The gravitational sector determines whether the NATIVE equation is physically viable as a fundamental theory. This is a qualitatively different and more consequential test.

3. **Natural sector transition.** The biology-side scaffold is frozen at a meaningful level (five bridges, stabilized M4/D4/L4/A4, T2/T3-conditional transport). Further biology-side work yields diminishing returns in terms of structural leverage. The gravitational sector is the next load-bearing frontier.

4. **The program's own architecture demands it.** Every terminal capstone since Book IV has listed "cosmological dynamics: not addressed" as a decisive boundary. Book X is the natural point to address this — the biology-side is complete enough to pause.

### 8.3 What the Gravitational Sector Must Address

1. **Gravitational bridge identification:** How does the native field Φ (or the gauge/matter sector) connect to spacetime curvature? Options include: Φ as conformal factor, emergent metric from soliton condensate, or explicit gravitational bridge postulate.
2. **Linearized GRUT-gravity:** Perturb around the vacuum. Derive wave solutions. Determine propagation speed, polarization content, and damping structure.
3. **Quadrupole radiation formula:** Derive the energy loss rate for binary systems.
4. **Hulse-Taylor test:** Compare P-dot_GRUT to P-dot_observed/P-dot_GR = 0.997 ± 0.002.
5. **Cosmological dynamics:** Expansion, CMB compatibility, large-scale structure (if the program proceeds that far).
