**Interlude (W1 — The Emergence Search):** Before any architecture decision, the program must know whether GRUT already contains a hidden route to emergent gravity. **Act 2 (Beta — The Premature Decision, Then Course Correction):** Beta initially produces an architecture-decision document offering two options: matter-within-GR (Option 2) or sixth bridge (Option 1). The decision document selects Option 2 and retires the ToE label. But this decision is premature — it collapses the option space before asking the harder question: can GRUT COMPLETE gravity rather than merely import or abandon it? The user's correction opens the frontier: GR is the correct recovered gravity in its tested regime; GRUT must show how that gravity is rebuilt through its own architecture AND what it adds beyond GR. Three layers are established: (1) current validated status (native fails), (2) conservative fallback (matter-within-GR), (3) frontier program (gravitational completion).

**Act 3 (Gamma + Delta — The Completion Route):** Gamma evaluates four candidate completion families: A (GR import — duplication), B (emergent metric — W1 excluded), C (GRUT-modified Einstein gravity — partial route), D (pseudo-completion — disqualified). Family C survives at 6/7 hard criteria. Delta turns Family C into a precise bridge design: the GRUT Gravitational Bridge (GGB), which installs Einstein-Hilbert as the metric-sector bridge coupled to GRUT's native Φ through T^Φ_μν (already computed in Phase 4 xAct). 3. **GW dissipation** (OPEN — not quantified): τ-relaxation introduces frequency-dependent modification to scalar perturbations coupled to the metric

**Act 4 (Epsilon — The Commitment Gate):** The GGB is design-ready. Is it commit-worthy? Epsilon evaluates: surplus portfolio is 1/3 demonstrated (singularity resolution alone). Cosmological screening uncomputed. GW modification unquantified. Binary-pulsar τ-constraint unverified. Committing a sixth bridge on one demonstrated surplus and two promissory notes is premature. Epsilon adopts Option C (hybrid stance): validated baseline (matter-within-GR) + declared frontier (GGB under quantification). Three commitment gates defined: (1) FRW cosmological computation, (2) scalar-tensor GW mixing quantification, (3) binary-pulsar τ self-consistency.

**Denouement (Terminal):** Book XI closes with the two-tier identity frozen. The committed ledger is unchanged (16/11/1/6) — all five stages + W1 were diagnostic. The option landscape is profoundly changed: from "gravity not addressed" to fully characterized two-tier regime. The next stage is Gate 1: FRW cosmological computation with T^Φ.

This arc — hardest gate → emergence excluded → premature decision corrected → completion route found → bridge designed → commitment deferred with explicit gates → two-tier identity frozen — is the structural spine of the manuscript.
