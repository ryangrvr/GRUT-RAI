### 9.1 The Ceiling

The fidelity ceiling is structural, not parametric. It cannot be lowered by tuning parameters — it is a consequence of the two-class pairing system's inability to distinguish monomers within a class. Crossing this ceiling requires either:

1. **Higher-specificity pairing:** A four-class (or higher) complement system where each monomer has a unique complement. This would require additional bonding features beyond the current donor-acceptor dichotomy.

2. **Error correction:** An enzymatic or catalytic mechanism that detects and corrects identity-level errors after assembly. This requires functional chains — chains whose structure enables them to perform chemical operations — which is the coding/catalysis problem.

Both routes require new structural content beyond what the current architecture provides. The fidelity ceiling is the natural boundary of the two-class system and defines the starting point for the next phase.

### 9.2 Why This Ceiling Matters

Without identity-level fidelity, the architecture cannot:
- Distinguish between two sequences that differ only within classes (e.g., K=8-K=6 vs K=9-K=6; both are D-A)
- Support a genetic code that maps specific triplets to specific functions
- Accumulate meaningful mutations (identity-level changes are noise, not variation)
- Support Darwinian evolution (which requires heritable variation + selection)

The class-level replication is sufficient for maintaining coarse structural information (branch patterns, chain topology, D/A ordering) but insufficient for fine-grained information processing. Biology requires the latter.
