## Status Classification

| Tag | Meaning |
|-----|---------|
| **Recovered** | Derived, computed, and verified within the GRUT framework. Matches known physics. |
| **Predictive** | Makes specific, testable, zero-parameter predictions beyond known physics. |
| **Partial** | Some structural results established; key closure conditions remain. |
| **Conditional** | Results depend on assumptions not yet fully justified. |
| **Open** | Legitimate GRUT entry point exists; no closure yet. |
| **Open frontier** | Natural target for GRUT machinery; no results yet. |
| **Explicit nonclaim** | GRUT does not claim this and says so. |
| **Speculative** | Legitimate extension with computed quantities, but core claims are conjectural. Clearly separated from established results. |

## Three Levels Within Each Sector

Every sector distinguishes:

- **Result** — already derived, computed, or verified
- **Entry point** — a legitimate extension path from existing GRUT machinery
- **Open question** — interesting but not yet anchored for claim status
